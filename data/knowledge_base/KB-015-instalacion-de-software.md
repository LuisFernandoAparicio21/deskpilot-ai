# Solicitar e instalar software autorizado

## Síntoma

Necesitas un programa que no está en tu equipo, o Windows pide permisos de administrador al intentar instalar o actualizar una aplicación. También aplica cuando una aplicación del banco solicita actualizarse y la instalación falla.

## Causa

Por seguridad, los equipos de Banco Altiplano no permiten instalar programas sin autorización. Solo se instala software del catálogo corporativo, y cada programa fuera del catálogo requiere la aprobación del jefe inmediato y una revisión de seguridad.

## Pasos

1. Abre el **Centro de Software** desde el menú Inicio de Windows.
2. Busca el programa por su nombre en el catálogo corporativo.
3. Si aparece, selecciónalo, da clic en **Instalar** y espera a que termine sin apagar el equipo.
4. Reinicia el equipo si el Centro de Software lo indica.
5. Si el programa no está en el catálogo, levanta una solicitud en el portal con el nombre del programa, su versión y para qué lo necesitas.
6. Tu jefe inmediato recibe la solicitud y debe aprobarla antes de que se programe la instalación.
7. No descargues instaladores de internet ni uses memorias USB para instalar programas.

## Cuándo escalar

- Escala como **P4** si es una solicitud nueva de software o una actualización que no es urgente.
- Escala como **P3** si una actualización obligatoria falla, pero puedes seguir trabajando con la versión actual.
- Escala como **P2** si una aplicación necesaria para operar dejó de funcionar porque no se pudo actualizar.
- Si un programa que no instalaste aparece en tu equipo o algún sitio te pide instalar algo para "verificar tu cuenta", desconecta el cable de red y escala de inmediato como **P1** a Seguridad de la Información.
